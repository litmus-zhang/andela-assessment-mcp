# Meridian Electronics Support Chatbot

This is an AI-powered customer support chatbot for Meridian Electronics, built using LangChain, Gemini, and Gradio.

## Setup

To run this locally, ensure you have the following environment variables:
- `OPENAI_API_KEY`: Your API key for the LLM.
- `AGENTIC_BASE_URL`: The base URL for the agentic API (e.g., OpenRouter).
- `OPIK_API_KEY`: For observability.
- `OPIK_PROJECT_NAME`: The name of your Opik project.

## Deployment

This app is designed to be deployed to Hugging Face Spaces.
